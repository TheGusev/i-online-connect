# Одноразовое назначение «Проверенного участника»

Выполнять на собственном сервере из каталога `server`, где настроен `DATABASE_URL` (окружение или `.env`). Миграция и новая сборка сайта не нужны.

```bash
node scripts/trust-existing.mjs --preview
node scripts/trust-existing.mjs --apply /защищённый/каталог/trust-2026-10-14.json
```

Замените путь на существующий приватный каталог вне публичной статики и репозитория. Файл создаётся с правами 0600 и никогда не перезаписывается. В нём только идентификаторы, прежние уровни и время изменения, без паролей и токенов. Сохраните его для отката.

Операция затрагивает профили пользователей с датой регистрации не позднее 14 октября 2026, 20:03 UTC, включая приостановленные, заблокированные и мягко удалённые аккаунты, но не меняет их ограничения и не восстанавливает аккаунты. Аккаунты без профиля отдельно подсчитываются; анкеты для них не создаются. `new` и `verified` становятся `trusted`; `trusted` и `ambassador` сохраняются. Видео-проверки, баллы, встречи, жалобы, роли и права не меняются.

Предварительный просмотр и итог выводят только количества. Повторный запуск не повышает более высокие уровни и не меняет уже назначенные. После выполнения обновите профиль и чат в приложении, чтобы увидеть розовый щит.

Откат:
```bash
node scripts/trust-existing.mjs --restore /защищённый/каталог/trust-2026-10-14.json
```

Если хотя бы один профиль изменился после назначения, весь откат отменяется: нужен ручной разбор, чтобы не затереть последующие изменения. Код статуса не служит доказательством фактической видео-проверки.
