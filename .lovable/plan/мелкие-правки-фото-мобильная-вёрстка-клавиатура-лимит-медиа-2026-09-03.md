# Мелкие правки: фото, мобильная вёрстка, клавиатура, лимит медиа

## 1. Битые фото в профиле и сообществах

Причина: файлы раздаются по пути `/media/...`, который на проде не проходит через Nginx к backend (наружу проксируется только `/api`), поэтому `<img>` получает 404 и показывает «битую» картинку.

- Раздавать файлы под API-префиксом: backend начинает отдавать их по `/api/media-file/*` (в дополнение к текущему `/media`, чтобы старые ссылки не сломались).
- `MEDIA_BASE_URL` по умолчанию → `/api/media-file`, `mediaUrl()` в клиенте склеивает его с `VITE_API_URL` для обоих вариантов пути.
- Добавить обработку ошибки загрузки картинки: вместо «битого» значка показывать мягкую заглушку с инициалами/иконкой (в `Avatar`, `MediaCarousel`, `MediaManager`, `SpaceCard`).
- Для видео в галерее показывать превью-плашку, а не пустой блок.
- Обновить `DEPLOY.md` / `SERVER-SETUP.md`: правило Nginx для медиа больше не обязательно.

## 2. Компактная шапка профиля на мобильном

Сейчас: огромное имя, под ним крупная карусель, ниже ещё раз те же фото — экран уходит вниз.

- Шапка: маленький аватар (главное фото) слева, рядом имя + «41 год» и бейдж доверия. Кнопки «Изменить» превращаются в компактную иконку-карандаш рядом со значением, без отдельной строки.
- Имя: `text-2xl` на мобильном, крупнее только с `sm:`.
- Крупную карусель на своём профиле убрать — остаётся один блок «Фото и видео» (сетка с управлением). Дубликата больше нет. На чужом профиле карусель остаётся, но ниже и с меньшей высотой (`aspect-[4/5]` → `aspect-square` на мобильном).
- Город переносится в строку под именем, без отдельной секции.

## 3. Клавиатура двигает экран и поднимает нижнее меню

- Заменить `interactive-widget=resizes-content` на `overlays-content` в viewport: клавиатура больше не сжимает layout.
- Нижнюю навигацию поднять над клавиатурой не даём: фиксируем `padding-bottom: env(safe-area-inset-bottom)` и скрываем нав, когда фокус в поле ввода на мобильном (в чатах поле остаётся видимым, нав скрывается).
- Поля ввода в чатах/пространствах: контейнер `sticky bottom-0` с учётом safe-area, автоскролл к последнему сообщению при фокусе.

## 4. Размер нижнего меню как во ВКонтакте

- Высота ряда ~56px, иконки `size-6`, подписи `text-[10px]`, плотнее (`py-1.5`), активный пункт — коралловая иконка + подпись.
- Одинаковые отступы для 5 пунктов, `truncate` на подписях, чтобы «Пространства» не ломало сетку.

## 5. Лимит фото/видео в профиле

- Максимум 5 фото + 1 видео-интро на профиль.
- Backend: проверка при `POST /api/media` — при превышении понятная ошибка 400 («Можно добавить до 5 фото»).
- Frontend: счётчик «3 из 5» в блоке «Фото и видео», кнопка «Добавить» блокируется на лимите с подсказкой.
- Описать лимит в `API.md`.
