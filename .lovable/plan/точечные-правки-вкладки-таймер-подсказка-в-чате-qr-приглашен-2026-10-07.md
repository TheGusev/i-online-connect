# Точечные правки: вкладки, таймер, подсказка в чате, QR-приглашение

## 1. Вкладки списка сообществ
- `SpacesTabs.tsx`: один ряд, `grid-cols-4`, `whitespace-nowrap`, 12px, uppercase, меньший letter-spacing, отступы `px-1 py-1.5`.
- На узких экранах (<380px) подпись «Создать своё» → «+ Своё», «По интересам» полностью.
- Проверка скриншотами на 360 и 390px.

## 2. Таймер
- Новый `src/components/ClockTimer.tsx`: ЧЧ:ММ (часы без ограничения), tabular-nums, двоеточие моргает только CSS (`steps(1)`, период 2 с: 1 с видно / 1 с нет, через opacity — ширина не меняется), при reduced-motion не моргает. Цвета/свечение как сейчас (розовый / акцент / красный по срочности).
- `ListingCountdown` использует `ClockTimer` — внешний вид прежний.
- `SpaceCard`: в правом верхнем углу текстовой части — таймер до `nextEvent.startsAt` (уже есть в данных списка). Если эфир идёт — «● ЭФИР» с пульсирующей точкой и временем эфира. Нет встречи и эфира — ничего. Заголовок получает правый отступ, чтобы не перекрывался.

## 3. Подсказка в чате
- `ChatComposer` получает флаг «есть сообщения»: тогда placeholder пустой, `aria-label` остаётся.
- В личном диалоге и чате сообщества скрываются стартовые подсказки/приветственный баннер, если сообщения уже есть.

## 4. QR «Пригласить»
- Зависимость: `qrcode.react` (SVG).
- Новый `src/components/InviteQrSheet.tsx`: BottomSheet, крупный QR на светлой подложке, ссылка, «Поделиться» (только если есть `navigator.share`), «Скопировать ссылку».
- Точка входа 1: пункт «Пригласить» в меню «⋯» сообщества — ссылка-приглашение, если есть, иначе `origin/spaces/:id`.
- Точка входа 2: «Поделиться приложением» в настройках (раздел аккаунта) — `window.location.origin`.

## Что может отличаться от задания
- Список сообществ не знает, идёт ли эфир в каждом сообществе (это известно только внутри открытого сообщества). Без новых запросов «● ЭФИР» на карточке будет показан только если это состояние уже есть в загруженных данных; иначе показывается только таймер встречи. Отмечу в отчёте.

## Отчёт
Изменённые файлы, новая зависимость `qrcode.react` отдельной строкой, отличия.
