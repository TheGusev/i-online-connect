# Демо-контент + мобильный вид как в макетах

Две части: (1) наполнение приложения демо-контентом с авто-вытеснением реальными данными, (2) доведение мобильных экранов «Профиль» и «Рядом» до вида из макетов.

## Часть 1. Демо-контент

### Пометка и вытеснение

- Additive-миграция `009_seed_flag.sql`: колонка `is_seed boolean NOT NULL DEFAULT false` в `profiles`, `listings`, `spaces`, `space_messages`, `user_needs`; индексы по `is_seed`.
- Выдача списков:
  - `/api/listings`: сортировка `is_seed ASC, created_at DESC`; демо-записи категории+города скрываются, когда реальных активных объявлений в этой паре стало 10 и больше.
  - `/api/matching` (лента): демо-анкеты идут после реальных и полностью пропадают, когда реальных подходящих в городе 10 и больше.
  - `/api/spaces`: тот же приоритет, порог 10 реальных сообществ.
- Демо не участвует в жизненной логике: демо-анкеты исключены из подбора для реальных совпадений, демо-объявления не рассылают уведомления по `user_needs`, отклик/чат на демо-запись возвращает понятное сообщение «Это демо-профиль для примера — реальные люди появятся рядом».
- Админка: в разделах жалоб/модерации фильтр «Скрыть демо», включён по умолчанию.

### Сид-скрипт

`server/scripts/seed-demo.mjs`, идемпотентный (уникальный тег в email/заголовке + `ON CONFLICT DO NOTHING`), запуск по SSH:

- 28 анкет: имена, возраст 18–45, разный пол, «о себе» разного тона, города Новосибирск + Москва, Санкт-Петербург, Екатеринбург, интересы из существующего справочника, 2–4 фото на анкету (для проверки каскадной карусели), часть верифицирована, часть нет.
- Объявления: по 8–10 в каждой из категорий (Знакомства, Услуги, Недвижимость, Транспорт, Вещи, Досуг, Попутчики, Срочная помощь) — заголовок, описание 2–3 предложения, цена где уместно, город и район, 1–3 фото, статус «активно».
- 7 пространств (спорт, книги, готовка, путешествия, настолки, айти, город) с обложкой, описанием, демо-участниками из п.1 и 3–5 сообщениями в чате.
- В конце — сводка в консоль: анкет, объявлений по категориям, пространств.

`server/scripts/clear-seed.mjs` — удаление всего демо одной командой.

### Картинки для демо

Сгенерирую набор нейтральных изображений: ~12 портретных аватаров и ~16 предметных/бытовых фото (квартира, авто, уборка, техника, мебель, йога, поход, книги и т.п.). Скрипт разносит их по анкетам и объявлениям, файлы кладутся в медиа-хранилище сервера и регистрируются в `profile_media`.

## Часть 2. Мобильный вид по макетам

### Профиль (IMG_0508)

- Шапка: назад, надпись-логотип по центру, колокольчик и «…» справа — компактно, в тёплой палитре.
- Каскадная карусель уже есть: доводим пропорции и глубину под макет, точки под ней, круглая кнопка-камера с «+» под точками (загрузка фото), проценты загрузки внутри кнопки.
- Под каруселью: имя + возраст крупно с коралловой галочкой верификации, ниже точка «Онлайн».
- Сетка карточек 2 колонки, каждая — иконка, мелкая подпись, значение. Берём только имеющиеся данные: цель знакомства, город, интересы, о себе, возраст, статус верификации, доверие. Новые поля в базе не добавляем.
- Редактирование остаётся: тап по карточке открывает тот же inline-редактор, что и сейчас.

### Рядом (IMG_0509)

- Шапка: круглая кнопка геолокации слева, «Рядом» по центру, кнопка фильтров справа.
- Чипы категорий — коралловые pill-кнопки с иконкой, активная залита коралловым, остальные белые с обводкой; в две-три строки, как в макете.
- Карточки объявлений: фото слева (скруглённый квадрат), справа заголовок в 2 строки, цена коралловым (или «Бесплатно»), плашка категории и плашка с городом/районом справа; иконка «в избранное» в углу.
- Нижняя навигация остаётся текущей (Лента, Рядом, Spaces, Чаты, Профиль), только стиль приводим к макету: коралловый активный пункт, компактные подписи.

## Техническая часть

- Миграция только additive; DTO расширяются новыми необязательными полями (`isSeed`, `district`) — старые клиенты не ломаются.
- Фронтенд читает `isSeed`, чтобы показать мягкую плашку «пример» и отключить отклик у демо-записей.
- Проверки: `tsgo --noEmit`, `npm run build:static`, прогон сид-скрипта на временной локальной базе, скриншоты 393×852 (лента анкет, «Рядом» с фильтром «Недвижимость», список пространств, профиль).
