# Клипы эфира отдельно от чата сообщества

Меняется только серверная часть эфира. Экран эфира не меняется. Клиент ответ на отправку клипа не читает (только ошибку), поэтому правка клиента не нужна.

## 1. Миграция `server/migrations/029_live_sessions.sql`
- `live_sessions` и `live_clips` — точно по заданию, всё через `IF NOT EXISTS`.
- Частичный уникальный индекс `live_sessions(space_id) WHERE ended_at IS NULL`, индекс `live_clips(session_id, created_at)`, `UNIQUE (session_id, author_id, client_temp_id)`.

## 2. `server/src/ws/live.ts`
- В состоянии сообщества появляется `sessionId`. Когда эфир реально начинается по `start_live`, создаётся строка `live_sessions`. Если запись в базу не удалась, эфир не стартует, ошибка пишется в лог.
- Экспорт `getLiveSessionId(spaceId)`.
- `endLive` (вручную и по 60-секундному таймеру) вызывает `closeLiveSession(sessionId)`. Эта функция берёт `media_url` клипов, удаляет файлы (`mediaPathFromUrl` + `unlink`, ошибки игнорируются), удаляет строки `live_clips` и ставит `ended_at = now()`. Всё в try/catch с логом.
- При регистрации канала закрываются все сессии с `ended_at IS NULL`. Раз в час чистятся клипы сессий, завершённых больше 24 ч назад, и закрываются зависшие сессии (открыты в базе, но нет в памяти). Таймер снимается в `onClose`.
- Чистые функции вынесены в `server/src/live/clips.ts`: `clipFilesToDelete(rows)` (только наши медиапути, без дублей и пустых) и `staleSessionIds(open, activeInMemory)`.

## 3. `POST /:id/voice` в `server/src/routes/spaces.ts`
- Ветка `live=1` идёт отдельно, до поиска в `space_messages`:
  - Нет активного эфира или нет `sessionId` → 409 «Эфир уже завершён». Файл ещё не сохранён, удалять нечего. Повторная проверка после перекодирования удаляет временные файлы.
  - Если клип с тем же `(session_id, author_id, clientTempId)` уже есть, возвращается он без новой рассылки. Вставка идёт через `ON CONFLICT DO NOTHING`. Если параллельный дубль проиграл гонку, его файлы удаляются и возвращается существующая строка.
  - После вставки вызывается `publishLiveClip` с id из `live_clips`.
  - Ответ: `{ id, clientTempId, audioUrl, mime, durationMs, createdAt, live: true }`.
  - Проверки длительности, формата и перекодирования — те же, что сейчас.
- Без `live` код не меняется.

## 4. Тест `server/tests/live-clips.test.mjs`
- Выбор файлов к удалению: чужие или пустые URL пропускаются, дубли схлопываются.
- Выбор зависших сессий.
- Решение об идемпотентности: если существующий клип найден, возвращается он.
- Не покрыто: SQL и реальное удаление файлов без базы.
