# «Я Онлайн» — рабочий каркас приложения

Собираем базовый скелет платформы знакомств: навигация, страницы-заглушки, слой API с мок-данными, i18n на русском, адаптивная разметка. Без Lovable Cloud, без Supabase, без встроенной облачной авторизации — все данные идут через внешний REST API.

## Одно важное уточнение по стеку

Проект уже работает на TanStack Router (файловый роутинг). React Router здесь установить нельзя — он несовместим с этим шаблоном. Роутинг сделаем на TanStack Router: те же адреса, те же возможности (вложенные лэйауты, параметры, типизированные ссылки). Всё остальное из требований выполняется полностью: Vite build даёт статику для Nginx, React Query + Zustand для состояния, react-i18next для текстов.

## Страницы

| Адрес | Содержимое заглушки |
|---|---|
| `/` | Лендинг: название, короткое описание, кнопки «Начать» и «Лента» |
| `/onboarding` | Шаги регистрации-знакомства (пустые шаги-заглушки) |
| `/feed` | Список кандидатов из мок-данных |
| `/profile/:id` | Профиль пользователя по id из мока |
| `/chat` | Список диалогов + пустая область переписки |
| `/spaces` | Список «пространств» (сообществ) |
| `/settings` | Язык интерфейса, заглушки настроек, уровень доверия |

## Навигация и адаптивность

- Mobile-first: нижняя панель навигации (Лента, Чат, Пространства, Профиль, Настройки).
- Desktop (≥1024px): боковая навигация слева, контент в контейнере с max-width.
- Общий лэйаут — в корневом маршруте, вокруг содержимого страниц.

## Слой данных

`src/api/` — единая точка доступа:
- `client.ts` — обёртка над fetch, база из `VITE_API_URL`, обработка ошибок, хранение токена.
- `mock/` — мок-адаптер с данными (пользователи, диалоги, пространства, уровни доверия).
- `endpoints/` — функции по домену: `auth`, `profile`, `matching`, `chat`, `spaces`, `trust`.
- Переключатель: если `VITE_API_URL` не задан (или `VITE_USE_MOCK=true`) — работают моки. Переход на реальный бэкенд = одна правка в `client.ts`.

React Query — кэш и запросы; Zustand — сессия пользователя и UI-состояние (открытое меню, выбранный диалог).

## i18n

`react-i18next` + `i18next`, ресурсы в `src/i18n/locales/ru.json` (и пустой каркас `en.json`). В компонентах только `t('ключ')`, никаких хардкод-строк. Переключатель языка — в настройках.

## Структура папок

```text
src/
  api/            client.ts, mock/, endpoints/, types.ts
  features/
    auth/ profile/ matching/ chat/ spaces/ trust/
      components/  hooks/  index.ts
  components/layout/   AppShell, SideNav, BottomNav
  i18n/           index.ts, locales/ru.json, locales/en.json
  store/          useSessionStore.ts, useUiStore.ts
  routes/         index, onboarding, feed, profile.$id, chat, spaces, settings
```

## Технические детали

- Новые зависимости: `zustand`, `i18next`, `react-i18next`.
- SEO: у каждого маршрута свой `head()` с русским title/description и og-тегами.
- Файл `.env.example` с `VITE_API_URL` и `VITE_USE_MOCK`.
- Дизайн-система: пока нейтральные токены из `src/styles.css`, без визуального оформления — как и просили, только каркас.
- Все запросы к бэкенду идут из браузера напрямую к внешнему API; серверные функции шаблона не используются, сборка остаётся статической.
