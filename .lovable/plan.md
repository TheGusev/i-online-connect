# Новая компоновка профиля (как карточка в ленте)

Обе страницы — свой профиль (`/profile/me`) и чужой (`/profile/:id`) — получают одну и ту же
конструкцию, как у карточки в ленте: крупное фото, поверх него имя и город, ниже компактные
сворачиваемые блоки.

## Шапка: фото во всю ширину

```text
┌─────────────────────────────┐
│  [видео-визитка]   [бейдж]  │
│                             │
│          ФОТО               │
│                             │
│  Мария, 34                  │
│  ⌖ Новосибирск   1/5  ● ○ ○ │
└─────────────────────────────┘
   [ ✍️ Написать ] [ ⋯ ]        ← чужой профиль
   [ ✎ Редактировать профиль ]  ← свой
```

- Фото — `aspect-[4/5]` на телефоне, шире на планшете; тап открывает кадр на весь экран
  (уже работает), свайп листает.
- Поверх фото: сверху слева метка «Видео-визитка», сверху справа бейдж доверия, снизу
  на затемнении — имя с возрастом и город. Отдельного аватара с дублем имени больше нет.
- Точки-индикаторы кадров — прямо на фото, у нижнего края.
- У своего профиля на фото остаются кнопка «+» (добавить кадр) и, для текущего кадра,
  «сделать главным» / «удалить» — но в виде компактных иконок в углу, не строкой под каруселью.

## Одна кнопка «Редактировать профиль»

- Вместо точечных карандашей у каждого поля — одна кнопка под фото. Она включает режим
  правки: у полей появляются рамки и подписи, внизу появляется панель «Сохранить / Отмена».
- Вне режима правки страница читается как обычная страница участника — без интерфейсных
  элементов между строками.
- Сохранение остаётся тем же (частичное обновление профиля), только собирается один раз
  при нажатии «Сохранить»; ошибки показываются понятным сообщением.

## Сворачиваемые блоки вместо общей «Свернуть»

- Кнопка «Свернуть всё» и её сохранённое состояние убираются.
- Каждый блок — отдельная сворачиваемая плашка с заголовком и краткой подсказкой:
  «О себе», «Ищу», «Интересы (12)», «Что важно (5)», а у своего профиля ещё
  «Фото и видео», «Приватность», «Верификация», «Только для тебя».
- По умолчанию открыты «О себе» и «Ищу»; остальные свёрнуты, чтобы страница влезала
  в один экран. Состояние каждого блока запоминается в браузере.
- Заголовки — в стиле игрового меню (капсом с розовой линией), как в остальном приложении.

## Нижняя панель действий

- Чужой профиль: закреплённая внизу строка «Написать» + иконка «ещё» (пожаловаться,
  заблокировать) — вместо текущей широкой панели.
- Свой профиль: нижней панели нет, только кнопка правки под фото.

## Дополнительно

- Нижнее меню полностью скрывается, когда открыта клавиатура (сейчас оно съезжает),
  и учитывает безопасную зону снизу.

## Технические детали

- Новый `src/features/profile/components/ProfileHero.tsx`: фото-карусель + оверлей
  (имя, возраст, город, бейдж, метка видео, точки), опциональные `onUpload/onDelete/onPrimary`;
  внутри переиспользуется `MediaViewer` из `MediaCoverflow.tsx` (вынести в отдельный файл
  `MediaViewer.tsx`, чтобы использовали оба).
- `ProfilePanel.tsx` — добавить запоминание открытости по ключу (`localStorage`), убрать
  `ProfileCollapseToggle.tsx` и `hooks/useProfileCollapse.ts` из обеих страниц.
- `profile.me.tsx`: локальный черновик (`useState` по полям) + режим `editing`; `InlineEdit`
  превращается в обычные поля внутри режима правки, `MediaManager` уезжает в блок «Фото и видео»
  (крупная карусель уже в шапке, дублирования нет).
- `profile.$id.tsx`: та же шапка, `ProfileActionBar` переводится в компактный вид.
- `BottomNav.tsx`: `useKeyboardOpen()` → не рендерить панель; `pb-[env(safe-area-inset-bottom)]`.
- Проверка: `npx tsgo --noEmit`, `npm run build:static`, скриншот 393×626 для обеих страниц.
