# Автообновление демо-контента + компактные карточки в ленте

## Что уже проверено

- Ежесуточное обновление демо-данных уже подключено в самом сервере: задача запускается в 04:00 по времени сервера и трогает только записи с пометкой «демо». Есть и ручной запуск командой `npm run seed:refresh`.
- Значит по первому пункту остаётся только одно: выполнить первый запуск вручную (в режиме плана менять состояние нельзя, сделаю после подтверждения) и добавить запуск при старте сервера, если данные давно не обновлялись — чтобы после деплоя лента сразу выглядела свежей, не дожидаясь 4 утра.
- На вашем скриншоте у карточки видны два пустых блока: пустая цитата «» и розовая плашка «Почему AI выбрал этого человека» без текста. Их надо просто не показывать, когда текста нет.

## Карточка в ленте: новая компоновка

Одна строка действий вместо трёх ярусов:

```text
[ ✍️ Написать ]  [ 🔖 На потом ]        [ ✕ ]
```

- «Написать» — главная розовая кнопка с иконкой карандаша/письма, занимает основное место.
- «На потом» — вторая кнопка рядом, иконка закладки; после нажатия иконка меняется на отмеченную закладку и подпись на «Сохранено».
- «Пропустить» — компактная круглая кнопка с крестиком справа, с подписью для читалок экрана и всплывающей подсказкой.
- На узком экране все три помещаются в один ряд: подписи у второй кнопки сокращаются, крестик прижат к правому краю.

Остальная компактность карточки:

- Фото ниже (примерно 62% ширины по высоте вместо почти квадрата), имя, возраст и город остаются поверх фото.
- Бейдж «Новый участник» переносится в правый верхний угол фото, чтобы не наезжать на имя.
- Интересы — максимум 4 чипа, дальше «+N».
- Пустая цитата и пустое объяснение от AI не выводятся; когда текст есть, объяснение показывается компактной строкой с розовой иконкой, без крупной плашки.
- Отступы внутри карточки уменьшаются на мобильном.

## Технические детали

- `server/src/index.ts`: после старта проверять давность последнего обновления демо-контента и при необходимости однократно вызывать `runSeedRefresh` (с защитой, чтобы не бегало при каждом рестарте чаще раза в сутки).
- Ручной первый запуск: `cd server && npm run seed:refresh`, вывод сводки в логе.
- `src/features/matching/components/MatchCard.tsx`: единый ряд действий (`flex items-center gap-2`), иконки `PenLine`/`Bookmark`/`X` из lucide, кнопка-иконка `size-9 rounded-full`, условный рендер цитаты и объяснения, `interests.slice(0, 4)` + счётчик остатка, высота фото через `aspect-[4/5]`/`h-64`.
- Правки только в презентационном слое ленты; логика реакций (`skip`/`save`/`like`) и API не меняются.
- Проверка: typecheck, `npm run build:static`, мобильный скриншот `/feed` 393×626.
