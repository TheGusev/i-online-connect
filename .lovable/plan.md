# «Проверенный участник» для существующих пользователей

## Что изменится
- Всем пользователям, уже зарегистрированным на момент запроса **14 октября 2026, 20:03 UTC**, назначить статус «Проверенный участник» и соответствующий розовый знак-щит, как на изображении.
- Новые регистрации после этого времени не затрагивать. Существующие более высокие уровни не понижать.
- Не менять оформление экранов, роли администратора, блокировки, результаты видео-проверки и историю общения. Назначение статуса не будет утверждать, что пользователь фактически прошёл видео-проверку.

## Выполнение и проверка
1. Перед изменением проверить реальные записи на вашем сервере: количество подходящих пользователей, распределение статусов и наличие профилей; отдельно учесть удалённые аккаунты и аккаунты без профиля, не восстанавливая их и не создавая вымышленные анкеты.
2. Подготовить одноразовую операцию с предварительным просмотром количества затрагиваемых записей и сохранением прежних уровней для отката. Выполнить изменение в одной транзакции.
3. Сверить количество обновлённых записей и проверить отображение розового щита в профиле и чате после повторного получения данных.
4. Добавить проверки: существующий пользователь получает нужный уровень, новая регистрация не затрагивается, более высокий уровень не понижается, результаты видео-проверки остаются прежними.

## Технические детали
- По прочитанному коду нужному статусу соответствует `profiles.trust_level = 'trusted'`; существующий `TrustBadge` уже отображает розовый `ShieldCheck` с подписью «Проверенный участник».
- Ограничить выборку через `users.created_at <= '2026-10-14T20:03:00Z'`. Не изменять `video_verified`, таблицу `verifications`, показатели встреч и жалоб.
- Изменение данных выполнить отдельной одноразовой командой для собственного PostgreSQL, без изменения схемы и без подключения Lovable Cloud.

## Ограничение
Доступ к рабочей базе вашего сервера ещё не подтверждён. Если он недоступен, будет подготовлена команда для запуска на сервере; назначение статусов нельзя считать выполненным до проверки реальных записей после её запуска.
