# Форма «Разместить», порядок категорий, сроки, прокрутка на «Рядом»

## 1. Форма «Новое объявление» не плывёт
- Обёртка формы: `max-w-full overflow-x-hidden`, у flex-детей `min-w-0`.
- Категории — сетка 3×3 (тот же `CategoryChips layout="grid"`, что на «Рядом»).
- Все input/textarea/select в `ds/Field.tsx` — минимум 16px (`text-base`), масштабирование не отключаем.
- «Срок актуальности» — ряд чипов с переносом строк вместо выпадающего списка; под ним «Объявление исчезнет: 18 окт, 14:30».
- «Опубликовать»/«Отмена» — липкая панель над нижним меню (с учётом safe-area), у формы нижний отступ под неё. Автофокуса нет.
- Блок срока при смене категории меняется плавно: fade + анимация высоты 200 мс (grid-rows 0fr→1fr), reduced-motion — без анимации.

## 2. Единый порядок категорий
- `CATEGORY_ORDER` в `src/features/nearby/labels.ts`: Срочно, Помощь, Услуги, Покупка/продажа, Жильё, Транспорт, Попутчики, Досуг, Знакомства.
- `categories`/`visibleCategories` сортируются по нему; используется в чипах «Рядом», форме, настройках потребностей и окне с замком.
- Форма открывается с «Срочно» или с категорией из `?category=` (передаётся кнопкой «Разместить» с «Рядом»). Для «Знакомств» без анкеты — существующее окно с замком, выбор не меняется.

## 3. Сроки по категориям
- Конфиг `LISTING_DURATIONS` (минуты, варианты + значение по умолчанию) в `src/features/nearby/durations.ts` и точная копия в `server/src/listings/durations.ts` (сервер собирается только из своей папки, общий файл невозможен). Тест сравнивает обе копии.
- Значения строго по заданию (Срочно 15м–24ч/1ч … Знакомства 7–30 дн/14 дн).
- Форма: при смене категории сохраняется выбранный срок, если он допустим, иначе ставится срок по умолчанию (чистая функция + тест). Подписи «15 мин», «3 ч», «3 дня», «30 дней».
- Сервер: `expiresInMinutes` — любое целое; при создании проверка по конфигу, иначе 400 `INVALID_DURATION`. Старое поле `expiresInDays` тоже проверяется. Тип `expiresInMinutes` в клиенте расширяется до `number`.
- Seed: сроки демо-объявлений берутся из допустимых вариантов своей категории, со смещением «уже прошло» для разного остатка; обновление `refresh.ts` ограничивает длительность допустимым максимумом категории. После изменения нужен повторный `npm run seed` (миграций нет).

## 4. Прокрутка на «Рядом»
- По нажатию/снятию категории — плавная прокрутка (~350 мс, ease-out, своя rAF-анимация) реального скролл-контейнера (ищем ближайшего прокручиваемого предка, иначе window) так, чтобы «Разместить» была в 12px под шапкой. Если уже там — ничего. Reduced-motion — мгновенно.
- Список: перекрёстное проявление 150 мс по ключу категории, skeleton-карточки при загрузке, аккуратное пустое состояние.
- Минимальная высота области списка `calc(100dvh - верх)`, чтобы прокрутка всегда доходила до точки.

## 5. Проверка
- Сборка и типы приложения; тесты: у каждой категории значение по умолчанию входит в её список, копии конфигов совпадают, серверная проверка срока (чистая функция), выбор срока при смене категории.
- Серверную проверку типов в этой среде выполнить нельзя (нет зависимостей сервера) — будет указано в отчёте вместе с тем, что не проверено в браузере.
