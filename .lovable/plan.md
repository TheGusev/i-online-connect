# Добавление кнопки «Свернуть» в профиль

## Цель
Дать пользователю возможность одним тапом скрыть/показать содержимое профиля, чтобы длинная страница не утомляла. Состояние запоминается в браузере.

## Что делаем

### 1. Хук для хранения состояния
- Создать `src/features/profile/hooks/useProfileCollapse.ts`.
- Ключ `ya-online-profile-collapsed` в `localStorage`.
- Значение по умолчанию — `false` (развёрнуто).
- Чтение из `localStorage` только в `useEffect`, чтобы не было mismatch при SSR.

### 2. Компонент переключателя
- Создать `src/features/profile/components/ProfileCollapseToggle.tsx`.
- Иконки `ChevronUp` / `ChevronDown` из `lucide-react`.
- Текст кнопки меняется: «Свернуть» / «Развернуть».
- `aria-expanded` и `aria-controls` для доступности.
- Стиль — призрачная/вторичная кнопка дизайн-системы (`Button variant="secondary"`), не бросается в глаза.

### 3. Оборачиваемые секции
В обоих профилях (`/profile/me` и `/profile/$id`) всё, что идёт после шапки с именем/возрастом и бейджем доверия, помещаем в оборачиваемую область:
- город;
- фото/видео (MediaCarousel, MediaManager);
- «О себе»;
- «Ищу»;
- интересы;
- ценности;
- в своём профиле — также настройки приватности, верификация и личная статистика.

При свёрнутом состоянии область скрыта; кнопка остаётся видна.

### 4. Интеграция в страницы
- `src/routes/profile.me.tsx`: добавить `ProfileCollapseToggle` под блоком `TrustBadgeExplained` и обернуть последующий контент.
- `src/routes/profile.$id.tsx`: аналогично — кнопка под шапкой, обёрнут весь контент до `ProfileActionBar`.

### 5. Визуальные детали
- Разделитель перед сворачиваемой зоной — мягкая линия `border-t`.
- Минимальная высота страницы сохраняется, чтобы футер/нижняя панель не прыгали резко.
- Кнопка выравнивается по правому краю или размещается рядом с заголовком — по месту смотрится аккуратнее.

## Проверка
- Собрать проект (`npm run build:static` или эквивалент).
- Открыть `/profile/me` и `/profile/123`.
- Нажать «Свернуть» — все обёрнутые блоки исчезают.
- Обновить страницу — состояние сохраняется.
- Убедиться, что кнопка видна и работает на мобильном экране.
