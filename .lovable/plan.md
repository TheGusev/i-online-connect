# Центр уведомлений, push-настройки и исправление клавиатуры

## Что будет сделано

### 1. Настройки станут заметными
- Добавить на страницу `/profile/me` явную кнопку «Настройки» и отдельный блок «Уведомления» со статусом push и переходом к управлению.
- На `/settings` сделать вкладку «Уведомления» доступной по прямой ссылке, чтобы переход из профиля сразу открывал нужный раздел, а не «Аккаунт».
- Показать понятный текущий статус устройства: включены, выключены, разрешение не запрошено, запрещены браузером, не поддерживаются, требуется установка на экран iPhone или сервер ещё не настроен.

### 2. Отдельный центр уведомлений
- Создать страницу `/notifications` в текущем тёмном стиле «Я Онлайн».
- Добавить вкладки-фильтры: «Все», «Чаты», «Встречи», «Совпадения».
- Показать полную историю с датой, непрочитанным состоянием, пустыми состояниями и подгрузкой более ранних записей.
- Добавить действия «Прочитать» для одной записи и «Прочитать все».
- Колокольчик в верхней панели будет открывать краткий список и давать явный переход «Все уведомления» в центр.

### 3. Полная история на сервере
- Расширить список уведомлений безопасной постраничной загрузкой и фильтрацией по типу.
- При создании встречи записывать уведомление участникам в историю, а не отправлять только push.
- Сохранить существующие уведомления чатов и совпадений; настройки типов продолжат управлять их доставкой.
- Отметка прочитанного останется привязана к текущему пользователю.

### 4. Глубокие ссылки
- Чат: открывать точный диалог `/chat/:conversationId`.
- Встреча: открывать нужное пространство `/spaces/:spaceId` и прокручивать/подсвечивать конкретную встречу, если передан `eventId`.
- Совпадение: открывать профиль второго человека `/profile/:userId`, как выбрано; из профиля остаётся переход в созданный диалог.
- Одинаково обработать ссылки из push, центра уведомлений, выпадающего списка и всплывающего уведомления внутри приложения.
- Если приложение уже открыто, активная вкладка будет переходить по ссылке без открытия лишнего окна; после восстановления сессии пользователь попадёт на нужный экран.

### 5. Push по каждому типу
- Оставить общий переключатель подписки устройства и добавить отдельные переключатели: сообщения, встречи, совпадения.
- Разделить общий статус подписки устройства и предпочтения типов событий, чтобы было понятно, почему уведомление может не прийти.
- При общем отключении сначала удалить подписку на сервере, затем отписать браузер; при частичной ошибке показать понятный статус и дать повторить.
- Синхронизировать состояние при возврате на страницу, смене разрешений и исчезновении подписки.

### 6. Клавиатура больше не двигает экран
- Исправить расчёт видимой области с учётом `visualViewport.offsetTop`, без двойного добавления высоты клавиатуры.
- Убрать дополнительный нижний отступ из общего каркаса и группового чата: сейчас он одновременно уменьшает экран и ещё раз добавляет размер клавиатуры.
- Для личного и общего чата оставить неподвижные шапку и строку ввода; прокручиваться будет только история сообщений.
- Нижнее меню скрывать при фокусе в поле и не позволять ему всплывать над клавиатурой.
- Проверить сценарий со скриншота на мобильном размере 393×626 и отдельно личный чат.

## Технические детали
- Добавить маршрут и метаданные для `/notifications`; ссылки оформить через TanStack Router.
- Расширить тип уведомления данными `conversationId`, `spaceId`, `eventId`, `withId` и единым вычислением адреса перехода.
- Для истории использовать cursor-пагинацию по `created_at + id`; фильтры проверять на сервере.
- При необходимости добавить индекс миграцией для быстрой истории по пользователю и типу; существующие данные сохраняются.
- Обновить API-документацию и инструкцию применения миграций на собственном сервере.

## Проверка
- Проверить фильтры, одиночное/массовое прочтение и счётчики колокольчика.
- Проверить переходы из каждого типа уведомления при закрытом и уже открытом приложении.
- Проверить включение, частичное отключение и полную отписку push.
- Проверить личный и общий чат с открытой клавиатурой на мобильных размерах, отсутствие наложения нижнего меню и сохранение последнего сообщения в кадре.
